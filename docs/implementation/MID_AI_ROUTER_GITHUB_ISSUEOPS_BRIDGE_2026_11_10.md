# MID AI Router — GitHub IssueOps alternative for ChatGPT Plus

Status: QA-only feasibility and public request packet, 10 November 2026; NO workflow configured, NO API call, NO GitHub issue created.

The user's existing ChatGPT GitHub plugin supports issue creation/labeling and issue-comment readback. MeteoMartini/MID is PUBLIC; GitHub Actions hosted minutes are free for public repositories. In contrast, full custom MCP action support is not established for ChatGPT Plus. A reviewed and gated IssueOps bridge could eventually use the native ChatGPT GitHub connector as an asynchronous public-only free-model review transport.

IMPLEMENTED: scripts/mid-ai-router-github-issueops.mjs composes a STRICT PUBLIC NONEXECUTABLE issue draft, with exact pinned Free candidate, main/stable SHA, version mirrors, explicit public-redacted confirmation and zero additional cash. It rejects obvious secrets, emails, unpinned model aliases, multi-call requests, version drift and missing consent. No issue, label, workflow, provider credentials, subscription or model dispatch is created by this code. This is only a coarse privacy filter; do not treat it as a sufficient guarantee that user content is public.

NOT IMPLEMENTED / BLOCKERS: trusted canonical ci/github/workflows and .github/workflows mirrored new IssueOps workflow after review; privilege-separated provider secret storage; signed approval and provider Free-account / data-policy proof; global atomic idempotent rate/usage ledger; exact issuer and actor validation; original-URL evaluation of real model output; full MID Source-PR -> controlled merge -> installer -> Worker/Pages -> Stable gates. Avoid privileged issue_comment scripts, pull_request_target, checkout of untrusted code, broad GITHUB_TOKEN permissions or automatic paid fallback. A public repository's issue body and comments are public; this path must not carry private conversations or secrets.

Potential later flow: ChatGPT via GitHub creates deliberately public one-shot task -> protected workflow on reviewed Stable (not PR head) checks owner/event/full SHA/independent issuer and Free plan -> atomic claim BEFORE provider fetch -> one pinned free-model call -> redacted, provenance-labeled public issue comment -> ChatGPT GitHub readback -> independent source verification. No auto-start or unattended billing. If exact user account and signer cannot be verified, no workflow activation.
