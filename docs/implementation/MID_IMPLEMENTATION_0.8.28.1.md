# MID v0.8.28.1

## Ensemble-Diagramme
- Gemeinsame, niedrigere Chart-Höhe und kleinere Achsenreserven sorgen auf schmalen Displays für mehr nutzbare Plotbreite.
- Legenden sind mobil einzeilig horizontal scrollbar statt unkontrolliert umzubrechen.
- Tagesbeschriftungen werden einheitlich leicht diagonal dargestellt.

## Tooltips
- Recharts-Tooltips öffnen nur noch auf Klick/Tipp (`trigger="click"`).
- Tooltip-Animationen, Cursor-Overlay und Backdrop-Blur wurden deaktiviert.
- Klick/Tipp außerhalb des jeweiligen Diagramms und Tooltips sowie Escape schließen die Anzeige.
- Temperatur-Tooltip: Niederschlagszeile ohne „Best Match“, engere Tmin-/Tmax-Spalten.
