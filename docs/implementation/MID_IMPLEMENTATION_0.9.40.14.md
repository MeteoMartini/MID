# MID v0.9.40.14

- Niederschlagsart-Overlay im Komposit meldet jetzt im Status eindeutig, ob der Layer aktiv ist und ob aktuell feste/gemischte Phasen im sichtbaren Ausschnitt vorhanden sind.
- Symbolik um Hagel sowie Graupel/Eiskörner erweitert; bestehende Symbole für Schnee, Mischphase und gefrierenden Niederschlag bleiben erhalten.
- Lesbarkeit über Distanzfilter und kleine semitransparente Markersymbole abgestimmt, damit Radarabstufungen weiterhin sichtbar bleiben.
