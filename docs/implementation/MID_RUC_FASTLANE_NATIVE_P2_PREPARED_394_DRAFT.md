Die beiden expliziten Freigabeflags bleiben `publicationAuthorized=false` und `realtimeConsumerEnabled=false`. Die bestehende vollständige 27h-/EPS20-Pipeline wird unverändert belassen.

Der Worker muss **ausdrücklich** die separaten Fast-6h-Daten mit Run-/ValidTime-/Feld-/Akkumulationsprovenienz bereitstellen.
