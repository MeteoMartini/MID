# MID v0.9.55.4 – 7-Tage-Trend: heutiger Niederschlag

- Die 7-Tage-Kurzinterpretation wertet für den ersten Prognosetag den vollständigen lokalen Kalendertag 00–24 Uhr aus.
- Bereits vergangene Niederschlagsphasen des aktuellen Tags bleiben im Tagestrend erhalten.
- Der verbleibende Tagesverlauf steuert weiterhin Bewölkungs-/Temperaturcharakter und zukünftige Gewitterrisiken; vergangener Niederschlag wird dadurch nicht fälschlich als zukünftiges Risiko formuliert.
