# MID v0.8.33.7

## Sprachliche Präzisierung
- „Trockener Radar-Nowcast“ entfällt. Die Anzeige lautet jetzt fachlich eindeutig: „Radarbefund: kein relevanter Niederschlag im Nahbereich“.
- Die Quellenzeile nennt strukturiert Datenstand, Aktualität, Radarqualität und die verwendete Radar-/Modellgewichtung.
- Der Prognose-Kompass verwendet die Begriffe „Prognoseentwicklung“, „Wahrscheinlichste Entwicklung“ und „Zunehmende Unsicherheit“.
- „Keine Hazards“ wurde durch „Keine Warnindikatoren“ ersetzt.
- Die Mehrquellen-Prognose wird als „qualitätsgewichtet“ und mit „Modellkonsistenz“ ausgewiesen.

Die meteorologische Berechnungslogik wurde nicht verändert.
