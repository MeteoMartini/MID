# Alpine snow FSC/GFSC – read-only qualification, 02.11.2026

**Origin:** verified MID v0.9.85.411 Stable SHA `9bf44c3354f98937fa058aac5d6dceb5895d29e5`. Candidate version .412 is not released.

## Exact official source semantics
- FSC Europe 20 m Daily V2 (BYOC `2bb9974a-0eb8-484d-adf1-20cc307021b6`): **FSCOG** is on-ground snow fraction; **FSCTOC** is top-of-canopy fraction. Corresponding distinct QA rasters, raw `QAFLAGS`, `CLD` cloud/shadow mask. Sentinel-2 optical observations, not snow depth.
- GFSC Europe 60 m Daily V1 (BYOC `0b5265f5-3664-44c2-96ab-e91aba67b0c3`): `GF`, `GF_QA`, `QAFLAGS`. Daily mosaic using available Sentinel-1/2 acquisitions over the preceding seven days; **product date is not per-pixel acquisition time**.
- Fraction 0–100 is percent; 205 cloud/cloud shadow, 210 inland water; anything else is not automatically snow-free. Quality classes 0 high, 1 medium, 2 low, 3 minimal. Original quality flags and cloud flags are carried raw, **their individual bits are deliberately not interpreted or smoothed before a current official bitmask verification**.
- A true 0% snow fraction is observed snow-free. NoData/water/cloud/unknown QA is **missing**, never 0 or a negative. This surface property is NOT snow height, fresh snowfall, snow-water equivalent or a forecast.
- `src/copernicusSnowObservation.ts` is a strict, side-effect-free boundary; `tests/unit/copernicus-snow-observation.test.ts` covers nominal, cloud, water, missing, source day, seven-day window, unsigned type and SHA. `productionApproved=false` is immutable. No API requests or user-visible map are activated.

## Browser PNG decompression and memory admission (read-only Draft)
The local PNG transport now reads the same-origin immutable asset as a **bounded stream**, rejects a mismatching declared HTTP Content-Length, any over-budget body, and more than 8192 fragmented chunks before SHA-256 or MapLibre handoff. The PNG structural envelope must have the standard signature, a CRC-checked IHDR, 8-bit non-interlaced RGBA with alpha, no animation or unknown critical chunks, contiguous IDAT and terminal IEND without trailing bytes. Maximum decoded envelope is 4096 px per axis and 8,388,608 pixels per image; compressed image bytes remain capped at 8 MB and must equal the attested manifest. This protects against compressed-to-huge-image and byte-stream resource exhaustion, not only SHA tampering. The renderer's existing eight-visible-tile cap remains.

Adversarial unit tests in `tests/unit/copernicus-snow-png-structure.test.ts` exercise oversize dimensions, missing alpha, interlacing, malformed chunk bounds, IHDR CRC, animation, trailing bytes, noncontiguous IDAT and over-budget streaming. The fixture is a PNG **structural** test, not an independently decoded real Copernicus image. This gate does **not** establish the original GeoTIFF pixel SHA, QAFLAGS/CLD/AT semantics, mask transparency, license/quota approval or production authorization. `productionApproved` remains false for all actual discovered source products; no live alpine layer is activated.


## Lokale Originalformat-GeoTIFF-Qualifikation (neuer read-only Gate)

`tools/snow/qualify_clms_cog.py` nimmt eine **lokal gespeicherte offizielle STAC-Feature-Beschreibung** und exakt alle lokal bereitgestellten TIFF-Bänder eines einzelnen FSC- oder GFSC-Produkts entgegen. Das Skript tätigt keine Netzwerkanfragen und verwendet weder CDSE-Zugangsdaten noch Processing Units. Der bestehende STAC-Vertrag prüft Produkt-ID, Bandnamen, Sammlung und UTC; die zusätzliche Prüfung verifiziert lokale TIFF-Byte-SHA256, UTM-Zone passend zur Sentinel-Kachel, 20-/60-m-Geometrie, Bandgleichheit, TIFF-Block-/Speichergrenzen, Rohdatentypen und rasterweise Masken. Eine echte 0%-Zelle zählt nur als **Kandidat**, wenn auch ihr Qualitätsraster gültig und unmaskiert ist. Wolken/Wasser/255, unqualifizierte Qualitätswerte und unbekannte Codes werden nicht als Nullschnee interpretiert. QAFLAGS/CLD/AT bleiben rohe, nicht dekodierte Originalbanddaten.

Die Ausgabe hält `localRasterBytesVerified=true`, aber **`authenticatedOriginalBytesVerified=false`**, `qaFlagsDecoded=false`, `productionApproved=false`, `mapConsumersVerified=false` und `authorizedDeliveryVerified=false` fest. Selbst eine erfolgreich durchgelaufene lokale TIFF-Prüfung beweist **nicht**, dass diese Bytes authentifiziert von CDSE stammen. Ein getrennt autorisierter, SHA-gebundener CDSE-Download/Provenienznachweis, der tatsächlich zutreffende 2026er Bitvertrag, die Rechte-/Quotenfreigabe und vollständige Browser/iOS/Widget-Abnahme fehlen weiterhin.

Die vier adversariellen Tests in `tools/snow/test_qualify_clms_cog.py` erzeugen ausschließlich synthetische, gekachelte GeoTIFFs mit Rasterio und prüfen FSC/GFSC-Bandmatrizen, falsche UTM-Zonen, geographische Drift, fehlende Bänder, Symlinks, veraltete Produkte und echte 0 gegenüber NoData/QA. Der read-only GitHub-Gate installiert binäre, versionsgebundene `rasterio==1.5.0` und `numpy==2.3.5` nur für Tests. Kein authentisches CDSE-GeoTIFF und keine produktive Schneekarte werden dadurch vorgetäuscht.
