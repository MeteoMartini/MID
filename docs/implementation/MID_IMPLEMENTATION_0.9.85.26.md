# MID-C7 · Implementierungsnotiz v0.9.85.26

## Kartenarbeitsraum

Die bestehende Kartenfunktion erhält eine sichtbare Komposition entsprechend dem Konzept: die drei fachlichen Ansichten werden als primäre Moduswahl geführt, Ebenen als eigene Steuerfläche und Datenstatus getrennt über der Karte. Beobachtungszeit, Modellzeit, Radar-/Satellitenfarben und vorhandene Legenden werden nicht verändert.

Auf kleinen Bildschirmen bleiben die Moduswahl und Layerkarten touchgerecht zweispaltig; Beschreibungen treten zugunsten der klaren Modusnamen zurück.
