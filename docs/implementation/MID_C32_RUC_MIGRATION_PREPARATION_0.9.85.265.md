## Concrete isolated replacement package

`tools/ruc/prepare_lossless_snapshot.py SOURCE NEW_TARGET` builds a complete `pages-lossless-candidate-v1` snapshot, including its actual final latest.json and every retained/native object. It is not imported by the hourly publisher. It reads only the verified existing grid.v2/pages-free-v1 inventory with the fixed900000000B budget, hashes every source, checks declared physical/logical geometry and streams whole-record parts <=524288 original bytes. Each part roundtrips Python, is named by full wire SHA under the same run's lossless-v2 namespace, and is deduplicated. Incompressible int16 parts still have a valid bounded gzip representation. Lookup/native/other payloads remain byte-identical. Existing pilot wire bytes are conservatively retained; original int16 raw files are absent only from this **separate candidate directory**.

Scientific grid/fields/scales/offsets/times/intervals are copied unchanged. Raw `.pages` descriptors of int16 products are replaced with `.compressedPages` entries: schema mid.ruc.compressed-pages.v1, records, recordBytes, run prefix and a contiguous list of firstRecord/recordCount/key/manifest. Logical aliases preserve all their original record ranges. Unused top-level R2 object descriptors are removed; source-manifest SHA preserves provenance. Earlier savedBytes/deduplicatedBytes counters move into migration.sourceAccounting, avoiding false replacement-storage accounting. The profile and migration.productionEnabled=false identify a non-active candidate, not production approval. Original source is verified again and remains intact as the rollback reference. Output is new, outside source, atomically renamed after all integrity/budget checks; failures remove incomplete output. No production, network, rights or publication mutation is implemented.

## Prepared bounded record reader

`tools/ruc/compressed_record_reader.mjs` imports the actual shared codec. It is deliberately **not** included in production Worker aggregates and defaults to profile-disabled on every call. Explicit offline opt-in is required. It validates the entire page's contiguous complete record coverage, safe same-run SHA-addressed keys, exact field sets, record/part geometry and wire/decoded bounds before transport. Caps: <=10million records/product, <=8192 parts/product, decoded<=524288B, wire<=524800B. Python producer enforces matching caps.

The exported preparedRucCompressedRecordReader singleton is available for a later one-per-isolate integration; isolated factories support tests. Two active wire/decode jobs,32 queued distinct jobs, coalesced identical requests, two verified decode entries and four30-second rejection entries bound the reader's additional work/state. Full queue returns explicit NoData. Queue wait and active work share a deadline of at most3000ms. Transport receives both declared byte limit and AbortSignal and must respect them; an uncooperative timed-out transport retains its active slot until completion, preventing unbounded background requests. Queued timeouts leave no queued job; no absent raw fallback or fabricated zero is attempted. Returned record copies cannot mutate verified cached chunks. Origin/path and canonical manifest identity separate cache entries. These caps are not a measurement of total Worker-isolate RAM.
