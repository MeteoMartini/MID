# MID v0.8.33.8

## Änderung
- In der Stunden-Detailansicht bleibt die Niederschlagsart ausschließlich im zentralen Stundenkopf sichtbar.
- Die Niederschlagskachel enthält darunter nur Menge und Wahrscheinlichkeit.
- Bei relevantem Gewitterrisiko erscheint in der Zusatzzeile kompakt `⚡ Gewitterrisiko … %`.
- Ohne Gewitterrisiko wird keine leere oder redundante Zusatzzeile gerendert.

## Umfang
Gezielte Darstellungs- und Informationskorrektur ohne Änderung der meteorologischen Berechnung.
