# MID v0.9.85.298

- Der RUC-Aktualitätsprüfer kontrolliert bei vollständig komprimierten Daten zusätzlich sichere Objektpfade, SHA-256-Deklarationen, ununterbrochene Datensatzketten und eine korrekte Bytebilanz.
